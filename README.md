# Cat Grid

A Vue 3 clone of the cat logic puzzle Meowdoku, which is itself a Star
Battle / Queens style puzzle. Place one cat per row, column and colored
region; cats may never touch, not even diagonally.

Research notes, design and roadmap: [docs/MEOWDOKU_RESEARCH.md](docs/MEOWDOKU_RESEARCH.md).

```sh
npm install
npm run dev     # start the dev server
npm test        # run engine tests (Vitest)
npm run build   # type-check and build
```
